# API Test Commands (cURL)

You can use these cURL commands in your terminal (or Command Prompt / PowerShell) to test the APIs.

## 1. User (Customer) APIs

### Send OTP (Login)
curl -X POST http://localhost:3000/api/user/login \
-H "Content-Type: application/json" \
-d "{\"phone\": \"9876543210\"}"

### Verify OTP
curl -X POST http://localhost:3000/api/user/verify-otp \
-H "Content-Type: application/json" \
-d "{\"phone\": \"9876543210\", \"otp\": \"1234\"}"

### Register User
curl -X POST http://localhost:3000/api/user/register \
-H "Content-Type: application/json" \
-d "{
  \"firstName\": \"John\",
  \"lastName\": \"Doe\",
  \"email\": \"john.doe@example.com\",
  \"phone\": \"9876543210\",
  \"address\": \"123 Main St, City\"
}"
